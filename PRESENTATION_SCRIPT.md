# Presentation script for the HiringMachine project

This file is a shorter guide for recording your presentation. The idea is to sound natural and clear.

## Suggested duration
- About 1 to 2 minutes

## Short script

"Hello, my name is [your name], and I will present the HiringMachine project."

"This is a fullstack application for sharing culinary recipes. Users can register, log in, create and edit recipes, rate them, and leave comments."

"On the backend, I used Laravel to build a REST API with JWT authentication and organized business logic. On the frontend, I used Vue.js, Pinia, and Tailwind CSS to create a modern and responsive interface."

"The project also includes filters by category and difficulty, as well as automated tests, which helped improve reliability and maintainability."

"I also used Docker to make the environment easier to run and reproduce."

"In short, HiringMachine is a complete application focused on user experience, solid architecture, and good development practices."

---

## Quick tips
- Speak slowly and naturally.
- Pause briefly between ideas.
- Look at the camera as if you were explaining to someone.
- If you get nervous, read the first sentence and then continue in your own words.
